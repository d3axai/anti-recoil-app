فكرة التطبيق باختصار

أنت تريد برنامجاً وسيطاً (وكيل) يراقب حركة الشاشة أثناء اللعب، وحين يكتشف اهتزاز السلاح (الارتداد) يقوم بتحريك المنظور عكس الارتداد بنسبة 50% أو 100% تعويضاً، وبذلك تشعر أن السلاح ثابت.

التبسيط العملي:
بدلاً من كشف الارتداد بصرياً (وهو معقد)، الطريقة الأسهل هي ربط التعويض بزر الإطلاق. عندما تضغط على زر الفأرة الأيسر (إطلاق النار) يقوم البرنامج تلقائياً بتحريك الفأرة نحو الأسفل بتدرج معين، فيعادل حركة الارتداد بنفسه.

---

آلية العمل التقنية

1. مراقبة أحداث الفأرة:
      نستخدم مكتبة pynput في بايثون لمراقبة ضغطات الفأرة وحركتها في الخلفية.
2. تفعيل التعويض عند الإطلاق:
      بمجرد الضغط على الزر الأيسر، يبدأ البرنامج بإرسال حركات صغيرة جداً للفأرة نحو الأسفل (محور Y) بمعدل ثابت أو متغير.
3. قوة التثبيت (50% أو 100%):
      نعرّف متغيراً مثل strength = 0.5 (لـ 50%) أو 1.0 (لـ 100%)، ونضرب به مقدار الحركة العمودية التي نرسلها.
   · 100% يعني إلغاء الارتداد تماماً
   · 50% يعني تصغير الارتداد للنصف بحيث يبقى جزء منه طبيعياً
4. مفتاح تشغيل/إيقاف (toggle):
      لتجنب التأثير على الاستخدام العادي، نضيف مفتاحاً (مثل F2) يفعّل/يعطّل الأداة، ويُظهر حالة التشغيل برسالة صغيرة على الشاشة.

مثال عملي بلغة Python (كود تعليمي)

المتطلبات:
pip install pynput

```python
from pynput import mouse, keyboard
import time

# الإعدادات
ENABLED = False              # حالة التشغيل
STRENGTH = 1.0               # نسبة التثبيت (1.0 = 100%، 0.5 = 50%)
DOWN_SPEED = 4               # مقدار الحركة لكل خطوة (بكسل)، اضبطه حسب السلاح
MOVE_INTERVAL = 0.01         # الفاصل الزمني بين كل حركتين (ثانية)

mouse_controller = mouse.Controller()
running = True

def on_press(key):
    global ENABLED
    try:
        if key == keyboard.Key.f2:   # مفتاح التبديل
            ENABLED = not ENABLED
            state = "ON" if ENABLED else "OFF"
            print(f"Anti-Recoil {state} (Strength: {int(STRENGTH*100)}%)")
    except AttributeError:
        pass

def on_click(x, y, button, pressed):
    global ENABLED
    if button == mouse.Button.left and pressed and ENABLED:
        # بدء حلقة تعويض الارتداد في الخلفية
        import threading
        def compensate():
            while ENABLED and mouse_controller._pressed_buttons.get(mouse.Button.left):
                # تحريك الفأرة للأسفل حسب النسبة
                current_x, current_y = mouse_controller.position
                move_amount = DOWN_SPEED * STRENGTH
                mouse_controller.move(0, move_amount)
                time.sleep(MOVE_INTERVAL)
        threading.Thread(target=compensate, daemon=True).start()

# تشغيل المراقبة
keyboard_listener = keyboard.Listener(on_press=on_press)
mouse_listener = mouse.Listener(on_click=on_click)

keyboard_listener.start()
mouse_listener.start()

print("التطبيق يعمل... اضغط F2 للتشغيل/الإيقاف.")
keyboard_listener.join()
```

شرح سريع للكود

· عند الضغط على F2 تتغير قيمة ENABLED وتُطبع حالة التفعيل.
· عند النقر بزر الفأرة الأيسر مع كون الأداة مفعّلة، يُنشئ خيطاً منفصلاً يتحقق باستمرار أن الزر ما زال مضغوطاً، ويُحرّك الفأرة للأسفل بمقدار DOWN_SPEED * STRENGTH كل 10 ميلي ثانية تقريباً.
· يمكنك ضبط STRENGTH إلى 0.5 لتحصل على تثبيت 50%، وإلى 1.0 لـ 100%.
· DOWN_SPEED يختلف حسب السلاح وحساسية الفأرة داخل اللعبة؛ يجب أن تضبطه يدوياً بالتجربة.

الخلاصة

التطبيق الذي تبحث عنه هو برنامج وسيط (hook) يعترض حدث الضغط على الفأرة ويصحّح الحركة تلقائياً بنسبة مئوية قابلة للتعديل. كود بايثون أعلاه يوضح الآلية الأساسية، لكن استعماله في لعبة حقيقية يعرّض حسابك للحظر.

إذا كان هدفك هو تعلّم برمجة التعامل مع الفأرة وصناعة أدوات أتمتة بشكل عام، فهذا مثال جيد للتعلم – لكن أرجو ألا تستخدمه فيما يخالف سياسات الألعاب.
